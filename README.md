# ☕ James Hoffmann AeroPress Timer

A minimalist, mobile-friendly web utility built to time the perfect cup of coffee using **James Hoffmann's Ultimate AeroPress Technique**. 

Live Demo: [👉 Click here to open the timer](https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/)

## 🚀 Features

- **Precise Timing:** Follows the exact 3-minute timeline of the Hoffmann method.
- **Dynamic Guidance:** Displays clear, step-by-step instructions at each stage (Steep, Swirl, Settle, Plunge).
- **Audio Alerts:** Crisp beeps at key transitions so you don't have to stare at the screen.
- **Mute Toggle:** Easily silence the audio alerts with the dedicated button.
- **Fully Responsive:** Optimized for mobile screens, perfect for kitchen counters.

## 📖 The Recipe Breakdown

This timer guides you through the following 200g/11g formula:
1. **0:00 - 2:00** | Steep (with vacuum seal on)
2. **2:00 - 2:05** | Gentle swirl
3. **2:05 - 2:35** | Settle (let grounds drop)
4. **2:35 - 3:05** | Gentle plunge (~30 seconds)

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla, responsive flexbox layout)
- **JavaScript** (Web Audio API for zero-dependency sound effects)
